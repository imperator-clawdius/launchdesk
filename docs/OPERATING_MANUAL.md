# LaunchDesk Operating Manual

## The product

LaunchDesk is the internal machine for turning small monthly service ideas into paid pilots. It is not a generic app builder. It is a filter that forces every idea through offer, distribution, fulfillment, and retention.

## Default offer

Start with:

`AI missed-call recovery + review automation for HVAC or plumbing companies.`

Initial pricing:

- Setup: `$997`
- Monthly: `$497/mo`
- Pilot: one location, one owner, one weekly report

## Daily loop

1. Add or clean 10 leads.
2. Send 20 direct outreach touches.
3. Follow up every reply.
4. Book one call or improve the offer copy.
5. Update lead stages.
6. End the day by exporting data.

## Weekly loop

1. Review which niche got replies.
2. Keep the best offer and kill weak variants.
3. Create one weekly report for every pilot.
4. Ask every interested owner for one referral.
5. Decide whether to raise price, tighten niche, or improve fulfillment.

## What not to build yet

- Multi-tenant auth
- A public app marketplace
- Full AI website generation
- Complex outbound automation
- Satellite sunlight clones or other capital-heavy concepts

Build those later only if this cockpit repeatedly turns offers into retained MRR.
