# Roadmap

LaunchDesk should grow only when growth helps people launch useful, ethical, small monthly services.

## Now

- Offer scoring.
- Launch copy generation.
- Lead tracking.
- JSON persistence.
- Operator authentication.
- Docker and Render deployment.

## Next

- CSV import and export for leads.
- Better score explanations in the UI.
- Editable launch asset templates.
- More niches with plain-language guidance.
- Keyboard and accessibility improvements.
- Beginner tutorial mode.

## Later

- SQLite or Postgres storage adapter.
- Proper login sessions and multiple operators.
- Stripe checkout for paid pilots.
- Twilio, Vapi, Retell, or email provider integrations.
- Scheduled weekly report generation.
- GitHub Pages documentation site improvements.

## Not Yet

- Public marketplace.
- Fully automated cold outreach.
- Generic app-builder claims.
- Guaranteed-income messaging.
- Complex CRM replacement features.

The rule: prove the manual workflow helps someone before automating it.
