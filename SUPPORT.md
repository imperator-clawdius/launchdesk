# Support

LaunchDesk is a free project. Support is community-driven.

## Start Here

- Read [README.md](README.md).
- Read [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for hosting.
- Read [docs/OPERATING_MANUAL.md](docs/OPERATING_MANUAL.md) for how to use it.

## Before Opening an Issue

Run:

```powershell
npm install
npm test
npm run smoke
```

Include the command output, your Node version, and what you expected to happen.

## What This Project Can Help With

- Packaging a small recurring service offer.
- Tracking early leads.
- Learning a practical launch workflow.
- Self-hosting a simple operator dashboard.

## What This Project Does Not Guarantee

LaunchDesk does not guarantee revenue, customers, legal compliance, deliverability, or business success. It is a tool for organizing the work.
